# 🔥 HabitFlow

HabitFlow is a simple habit tracking web application built with **React, TypeScript, and Tailwind CSS**. It allows users to create habits, track their daily progress, build streaks, and keep their habits saved between visits.

## ✨ Features

- ➕ Add new habits
- 🗑️ Delete habits
- ✅ Mark habits as completed for each day
- 📅 View habits across the week
- 🔥 Track completion streaks
- ⬅️➡️ Navigate between weeks
- 💾 Save habit data using LocalStorage
- 🚫 Prevent tracking habits on future dates
- 📱 Clean and responsive interface

## 🛠️ Technologies Used

- ⚛️ React
- 🔷 TypeScript
- 🎨 Tailwind CSS
- 📅 date-fns
- 💾 LocalStorage
- ⚡ Vite
- 🧩 tailwind-merge

## 🚀 How It Works

Users can enter a habit they want to track and add it to their habit list. Each habit displays the days of the week, allowing the user to mark individual days as completed.

HabitFlow also calculates the user's current 🔥 streak and stores habit information in the browser using LocalStorage, so progress remains available after refreshing or reopening the application.

## 📥 How to Download

1. Click the green **Code** button at the top of the repository.
2. Click **Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the extracted folder in **Visual Studio Code**.
5. Open the terminal and run:

   npm install

6. Once the dependencies have finished installing, run:

   npm run dev

7. Open the local URL shown in the terminal to use HabitFlow.
